Проверены ограничения истории и ролей, пустая история, валидируемый поиск только в публичной области, исключение личных данных и описаний из контекста модели, ограничение числа вызовов инструмента, отсутствие ключа и ошибки провайдера. API проверяет CSRF и отдельное ограничение 10 сообщений в минуту. Браузерный сценарий проверяет безопасный текст и внутренние ссылки, повтор после сбоя, мобильную панель, закрытие Escape и возврат фокуса, сообщение при отсутствии настройки модели. Снимок мобильной панели: `output/playwright/assistant-mobile.png` (локальный файл, не включён в Git).

Независимое ревью нашло сбой при пустой истории; исправление подтверждено тестом, воспроизведшим ошибку до изменения. Подтверждённых уязвимостей SQL/XSS, раскрытия ключей и приватных полей не обнаружено.

## Границы публикации

GitHub подключён к проекту Vercel `mesto-realty` с автоматической публикацией main. Адрес: https://mesto-realty.vercel.app. До обновления проверены ответы API: `/api/health` и `/api/assistant` возвращают 404. В Vercel нет переменных окружения проекта, в том числе ключа модели или настроек PostgreSQL. Текущая публикация — статические файлы; она может показать новый интерфейс, но не выполнять серверные функции приложения.

Реальный платный вызов модели не выполнялся: API-ключ не предоставлен. Чтобы агент отвечал на рабочем сайте, необходим работающий Express-сервер с PostgreSQL, `AI_API_KEY`, `AI_MODEL` и подходящим HTTPS-адресом. Docker-запуск сохраняется. Упоминание Dockhost в истории Git не подтверждает наличие доступа к контейнеру или его домену.
