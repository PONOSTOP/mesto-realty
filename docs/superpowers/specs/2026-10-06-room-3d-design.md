# Автоматический 3D-просмотр помещений

Дата: 6 октября 2026 года. Проект: Место Бизнес.
Статус: проект решения для согласования, реализация ещё не начата.

## Поведение

После успешной загрузки фотографий сервер автоматически ставит реконструкцию помещения в очередь. Отдельная кнопка запуска не нужна. Запуск происходит после короткой паузы после последней загрузки, чтобы несколько партий фотографий не создавали несколько платных обработок. Готовый результат появляется в блоке «3D-просмотр помещения» рядом с описанием объекта. Любой посетитель, включая неавторизованного, может просматривать модель опубликованного объявления. Для черновиков и снятых объявлений результат доступен только владельцу.

## Варианты

1. Рекомендуется реконструкция по фотографиям через COLMAP и Nerfstudio Splatfacto на отдельном GPU-обработчике. Она восстанавливает наблюдаемое пространство и позволяет отображать его в браузере через Gaussian Splatting. Требует настройки GPU-инфраструктуры и достаточно связной серии снимков.
2. Внешний сервис реконструкции: меньше собственного сопровождения, но нужны проверенный API для помещений, ключ и оплата. Подключать только после проверки документированного API на реальной серии снимков комнаты.
3. Генерация приблизительного интерьера по отдельным фотографиям: может выдумывать планировку и детали, поэтому не подходит для основного просмотра объекта недвижимости.

## Загрузка и качество

Текущий лимит — 10 фотографий на объект. Предлагается увеличить лимит до 200, сохранив загрузку небольшими партиями и текущую проверку JPEG/PNG/WebP. Практическая подсказка — снимать комнату последовательно с разных точек с большим перекрытием, ориентировочно 30–100 снимков; это рекомендация, а не гарантия результата. Порог автоматической попытки — 20 фотографий, настраиваемый на сервере. Даже достаточное количество снимков не гарантирует их совмещения. Несвязанные комнаты или обычные разрозненные фотографии могут не реконструироваться.

При нехватке фото владелец видит подсказку. При невозможности реконструкции он видит понятную причину и может добавить снимки. Посетителям показывается только готовый результат; фотографии и описание доступны независимо от обработки.

## Архитектура

Express принимает фотографии и транзакционно обновляет версию набора снимков и задание в PostgreSQL. Очередь сохраняется при перезапусках. GPU-обработчик забирает задания через закрытый API с отдельным серверным токеном, получает снимки конкретной версии, выполняет COLMAP, обучение Splatfacto и экспорт Gaussian Splatting в PLY. Результат и параметры начального ракурса передаются сайту и сохраняются на постоянном диске. Обработчик имеет ограничения времени, размера результата и числа попыток; одновременно выполняется одно задание по умолчанию.

Изменение набора фотографий делает предыдущую версию неактуальной. Поздний ответ старого задания не заменяет новую модель. Удаление объекта отменяет задания и удаляет артефакты. Снятие объявления немедленно закрывает публичный доступ к артефактам. При отсутствии настроенного обработчика интерфейс владельца сообщает, что обработка недоступна; готовность модели не имитируется.

## Просмотр

Браузерный просмотрщик Gaussian Splatting загружается по действию «Открыть 3D-просмотр», чтобы не замедлять описание объекта. Поддерживаются мышь, касания, приближение, сброс ракурса и полноэкранный режим. При отсутствии WebGL2 отображается понятное сообщение. Библиотека и её зависимости хранятся локально и согласуются с существующей CSP. Артефакты выдаются сервером с проверкой доступа на каждом запросе, без постоянных публичных ссылок на черновики.

## Проверка

Проверить очередь после загрузки, объединение партий, восстановление после перезапуска, отказ при недостаточном числе фото, отмену устаревших версий, ограничения доступа, удаление артефактов и обработку ошибок. Проверить страницу объекта в настольном и мобильном браузере. Полный цикл подтвердить на реальной серии снимков помещения с действующим GPU-обработчиком; подменённый результат в тестах не является подтверждением работы реконструкции.

## Условие запуска

В текущем Docker-образе сайта нет COLMAP, Nerfstudio или GPU-обработчика. Для реальной автоматической генерации потребуется отдельный GPU-сервер либо выбранный совместимый сервис. До этого можно реализовать и проверить интеграцию сайта, но нельзя заявлять, что генерация уже работает на опубликованном сайте. Аренда вычислительных ресурсов и подключение платного сервиса согласуются отдельно.
