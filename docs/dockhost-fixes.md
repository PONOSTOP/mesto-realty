# Исправление чата и фотографий Dockhost

5 октября 2026 года.

## Причины

- Ключ и модель ИИ не настроены: прежний чат блокировал отправку.
- База сохраняла ссылки на демофотографии, но `/app/uploads` оказался пуст после пересборки контейнера. Живые URL возвращали 404 с ENOENT.

## Исправления

Без настроенной модели сервер включает явно обозначенный подбор по каталогу: город, назначение, аренда/покупка, бюджет в рублях и площадь в м². Он уточняет город, сохраняет условия в диалоге, показывает реальные опубликованные объекты и сообщает об отсутствии совпадений. После настройки `AI_API_KEY` и `AI_MODEL` и перезапуска контейнера автоматически используется модель.

Повторный seed восстанавливает отсутствующие первые фотографии известных демонстрационных объектов из локальных иллюстраций, сохраняя существующие URL, данные базы и имеющиеся файлы. Никакие пользовательские оригиналы в репозиторий или Docker-образ не добавляются. Для сохранности пользовательских загрузок нужен постоянный диск, подключённый к `UPLOAD_DIR` (по умолчанию `/app/uploads`).

## Проверка

- `npm test`: 22 проверки проходят, в том числе восстановление отсутствующего файла без перезаписи существующего, отбрасывание небезопасного имени файла и подбор с бюджетом/площадью в нескольких сообщениях. Исправления по ревью: неизвестный новый город не сохраняет предыдущий, замена диапазона площади очищает старые границы.
- `npm run test:api`: 20 проверок проходят, включая реальный ответ подбора без ключа, CSRF и лимит запросов. Интеграционный тест трижды запускает настоящий seed в изолированной схеме тестовой базы: после удаления файла прежняя ссылка восстанавливается, изменённая цена сохраняется, дубликаты не появляются.
- `npm run test:browser`: 13 проверок проходят, включая отправку без модели, безопасные карточки и мобильную панель.
- `npm run format:check` и `git diff --check` проходят.

Настройку ключа и модели пользователь выполняет в Dockhost. Реальные ответы модели до этого не заявляются.
