# Место Бизнес — переход на коммерческую недвижимость

Задача пользователя: полностью убрать жилую недвижимость с сайта, переделать оформление и продукт под B2B. Стек сохраняется: HTML/CSS/JavaScript, Express и PostgreSQL.

## Решение
Деловая площадка для арендаторов, собственников и брокеров. Светлые поверхности, графитово-синий текст, синий акцент, строгая сетка, архитектура офисных зданий. Бренд «Место Бизнес». Главная: деловой заголовок, поиск и шесть коммерческих направлений. Без квартир, домов, комнат, студий и потребительских текстов о жизни/уюте.

Категории API: office, retail, warehouse, industrial, free_purpose, commercial_land. Сделки sale/rent сохраняются. Поле rooms удаляется из API, форм и БД. Новые характеристики: buildingClass ('',A,B,C), floor (nullable int -5..150), ceilingHeight (nullable numeric >0..50), powerKw (nullable numeric >0..100000), parking (boolean), tax (included,excluded,no_vat,unspecified). Все дополнительные характеристики необязательные.

Профиль и регистрация: company (строка 0..120), businessRole (owner/broker/tenant, default owner). Private user и public owner возвращают company,businessRole; email по-прежнему только приватный. Контактное имя — человек, компания — отдельное поле.

Фильтры API дополнительно: buildingClass, minCeilingHeight, minPowerKw, parking=true/false. Все фильтры SQL и URL, пагинация сохраняется. Неподдерживаемые жилые category отвергаются 422. Старый rooms не должен принимать значения: остаточные URL-параметры удаляет frontend.

## Миграция
Перед применением создать приватную резервную копию БД в .local. Миграция 002 удаляет все старые демонстрационные объекты и объекты жилых категорий apartment/house/room/land, каскадно фото и избранное. Существующий недемонстрационный commercial переводится в free_purpose. Пользователи и сессии сохраняются. Неизвестные коммерческие объекты не переименовываются в офис без оснований. Старые файлы остаются только в закрытом uploads до безопасной очистки; публичные изображения и seed полностью заменяются коммерческими.
