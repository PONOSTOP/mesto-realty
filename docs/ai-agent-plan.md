# План реализации ИИ-агента

Согласованная схема: [ai-agent-design.md](ai-agent-design.md).

- [ ] Написать и запустить падающие тесты сервиса: валидация истории, поиск через инструмент, публичные поля, некорректные вызовы, отсутствие ключа и ошибки провайдера.
- [ ] Добавить `server/assistant-service.js`: OpenAI-совместимый Chat Completions API, ограниченный инструмент поиска через `searchSchema`, максимум три шага поиска, тайм-аут 25 секунд, до шести карточек и безопасное публичное представление.
- [ ] Добавить `server/assistant.js` и подключить к Express: GET состояния, POST диалога, существующий CSRF и отдельное ограничение частоты. Настройки — `AI_API_KEY`, `AI_MODEL`, `AI_BASE_URL` на сервере.
- [ ] Добавить `public/js/assistant.js`, стили панели и подключение: доступное окно, безопасный текст, карточки со ссылками, история в памяти, повтор после ошибки, каталог при недоступной модели.
- [ ] Проверить серверные тесты, существующие тесты проекта и мобильный/клавиатурный сценарий в браузере.
- [ ] Обновить README и `.env.example`, зафиксировать и отправить проверенные изменения в существующий репозиторий по SSH. Его текущая публичная видимость не меняется.
- [ ] Проверить доступный путь публикации и рабочий сайт. При отсутствии доступа указать конкретные недостающие настройки; отправка Git не считается подтверждением публикации.

Новые зависимости не требуются. Ключи и личные данные не попадают в Git или браузер. Тесты провайдера используют контролируемый HTTP-ответ, реальный платный вызов выполняется только после настройки ключа.
